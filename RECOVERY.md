# Recovery guide

1. Use Guardian emergency stop and confirm automated input is disabled.
2. Treat unfinished tasks as `INTERRUPTED`; do not silently resume them.
3. Review the last SQLite checkpoint and audit events.
4. Inspect the cause of any RED health state before starting another session.
5. After power loss or Windows restart, do not auto-launch the VM or Operator.
6. Start a new session only after explicit owner approval.

ANDREWS cannot undo an action already accepted by an external website.
